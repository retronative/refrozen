# Code of conduct

reFrozen adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in this repository's issues, pull requests, discussions and
reviews, and wherever someone represents the project.

## In short

- Be respectful and welcoming; disagree about ideas, not people.
- No harassment, insults, personal or political attacks, sexualised language or imagery, or
  publishing others' private information.
- Keep to the project's rules in [CONTRIBUTING.md](CONTRIBUTING.md): in particular, never share or
  ask for game files, CD keys or cheats.

## Reporting

Report a problem through GitHub: use **Report content** on the issue, pull request or comment
(the **…** menu), or **Block or report** on the user's profile. This reaches the maintainers and
GitHub's moderation, and keeps your report private. Please don't report conduct problems in a
public issue. Security problems go through [SECURITY.md](SECURITY.md) instead.

## Enforcement

The maintainers review every report and act on it as the Contributor Covenant's enforcement
guidelines describe: from a private note, through hiding or deleting content and locking threads,
to blocking an account from the repository. GitHub's own
[Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)
apply in addition.
