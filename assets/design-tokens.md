# reFrozen design tokens

The app icon is the master visual reference for the website, the macOS app icon and the DMG.
This file records the tokens taken from it. The CSS source of truth is the `@theme` and `:root`
blocks in `.website/src/styles/main.css`; `npm run check:contrast` (in `.website/`) checks the
text and UI colours below.

The file is named for its role, not its artwork title. That way the build script, the packaging
and this document keep working if the artwork is redrawn, and the name follows the repository's
lowercase-hyphen style. Every derived size comes from `scripts/make_icons.sh`.

`assets/icon/refrozen-icon-small.svg` is a simplified drawing of the master for 16 and 32 px, where
the master's cracks and studs turn to noise. It was drawn for this project from the master: same
frame, stone and trident, heavier strokes.

## How the colours were sampled

Every opaque pixel (alpha ≥ 250) was classified by HSL into material families. For each family
the per-channel median and quartiles (p25/p75) were taken. The families were: gold (hue 25–50°,
saturation > 0.25) split by lightness; ice (hue 195–225°) split by lightness and saturation; glow
(hue 205–230°, saturation > 0.7); stone (the inner field, lightness < 0.14 or < 0.3 for blue-lit
stone); and frost (saturation < 0.15, lightness > 0.75). The script was a throwaway decoder plus
classifier in Node and is not part of the repository.

## Tokens

Colour roles are kept separate so that text always meets AA. Ornament colours are only checked
for 3:1 (WCAG 1.4.11, non-text).

### Icy crystalline blue: the primary magical accent

| Token | Value | Source | Use |
|---|---|---|---|
| `--color-frost` | `#88d3f9` | ice crystal p75 | links, frost buttons, focus ring, "in progress" status (text-safe) |
| `--color-ice` | `#6bc4f4` | ice crystal median | ornament fills, ice cores in dividers (non-text) |
| `--color-ice-core` | `#dfedfa` | ice core median | frosted highlights, arrow tips, specular lines |
| `--color-frost-deep` | `#156ec5` | glow blue p75 | borders and tints only, never text (3.9:1 on abyss) |

### Weathered antique gold: borders, ornaments, secondary accents

| Token | Value | Source | Use |
|---|---|---|---|
| `--color-gold` | `#d4ae7a` | between gold mid p75 and gold highlight p25, lifted for AA | eyebrows, labels, list markers (text-safe) |
| `--color-gold-bright` | `#eed2a7` | gold highlight median | headings on wood, selected states, polished edges |
| `--color-gold-deep` | `#ab7f52` | gold mid median | borders, ornament bodies (non-text; 4.1:1 on lit stone) |
| `--color-gold-shadow` | `#47301c` | gold shadow median | ornament outlines, the dark end of metal gradients |
| `--gold-metal` | `linear-gradient(135deg, #eed2a7, #ab7f52 48%, #47301c)` | | four-point studs and small metal ornaments |

Frames and plates use bronze-brown gradients (`#4a3420`, `#36281a`, `#181009`, `#0d0905`) taken
from the icon's gold in shadow, in place of the earlier olive-brown.

### Dark cracked stone: surfaces and backgrounds

| Token | Value | Source | Use |
|---|---|---|---|
| `--color-abyss` | `#05080e` | stone, deep (median) | page, `theme-color`, manifest background |
| `--color-slab` | `#0b121b` | stone median, desaturated | callouts, cards |
| `--color-slab-2` | `#111a26` | | raised stone, keys, skip link |
| `--color-seam` | `#233044` | stone p75, lightened | hairlines and borders between stones |
| panel base / lit / shadow | `#0d151f` / `#152030` / `#080d14` | | `.slab`/`.panel` gradients |

Text stays as it was: `--color-bone` `#ece6d8` (parchment, matched to the warm gold) and
`--color-ash` `#a7afbc`. The status hues stay too, because they carry meaning: verdant `#a3d58c`
(passed), dusk `#b1a4f4` (future), frost (in progress) and ember `#e59a5b` (unverified). The new
language changes their shape (a stud, a tint, a frosted edge), not their hue.

### Frosted metallic highlights

- `--frost-edge`: `inset 0 1px 0 rgba(223, 237, 250, .12)`. A cold specular line on the upper edge
  of buttons and pills, like the frost on the icon's frame.
- `--bevel` (unchanged): a warm key light from the upper left.

### Subtle blue glow: focus, hover and active

- `--glow-ice`: `0 0 18px -4px rgba(79, 178, 235, .55)` on hover for tab sockets and FAQ tablets.
- `--glow-ice-inset`: `inset 0 0 18px rgba(79, 178, 235, .22)` inside clipped shapes (buttons,
  pager plates), where an outer shadow would be clipped, and on `:active`.
- Focus is never only a glow: `:focus-visible` is always a solid 2 px `--color-frost` ring
  (12.2:1 on the page, 8.0:1 on the frost button). The glow only adds to it.
- Hover text on navigation links gets `text-shadow: 0 0 12px rgba(79, 178, 235, .45)`.
- All of these are transitions, so the global `prefers-reduced-motion` rule makes them instant.
  Nothing new loops.

### Gothic fantasy geometry: frames and dividers

- `--star`: the icon's four-point stud as a clip-path,
  `polygon(50% 0, 61% 39%, 100% 50%, 61% 61%, 50% 100%, 39% 61%, 0 50%, 39% 39%)`. It is used as the
  current-page mark in the navigation, as mid-edge studs on carved frames and the minimap frame,
  as the status-pill marker (a rotated square there, for legibility at small sizes) and at the
  centre of the divider.
- Corner ornament (`CarvedFrame.vue`): a curved spike with a stud, after the icon's frame corners.
- Divider (`Divider.vue`): two small studs, a large four-point star and an ice core.
- Shapes that already existed stay: chamfered plaques (`.chamfer`), pointed-hex buttons and notched
  pager plates.

## Derived assets

`scripts/make_icons.sh` makes all of these from the two sources, byte-identically on every run.
`tests/test_brand_assets.py` checks that the committed files match a fresh run.

| Output | Source and geometry |
|---|---|
| `assets/icon/reFrozen.icns`: `icon_16x16`, `icon_16x16@2x`, `icon_32x32` | small drawing on a 14/16 body (14 px on 16, 28 px on 32) |
| `reFrozen.icns`: `icon_32x32@2x` (64 px) and 128–1024 px | master on Apple's macOS grid: frame centred, 824 px body on 1024 (about 80%), transparent margin |
| `.website/public/favicon.ico` | 16 and 32 px: small drawing, full bleed; 48 px: master |
| `favicon-32.png` | small drawing, full bleed |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (180), `brand/mark-{96,144}.png` | master, full crop |

At 64 px the master is still legible (48 px already reads in the previews), and 64 px is what
Retina screens show for 32 pt sidebar and toolbar icons, so `icon_32x32@2x` keeps the detail.

Web icons keep the master's fuller crop. A browser tab draws a favicon edge to edge with no
neighbouring app icons to match, and iOS masks touch icons to its own rounded square and fills
transparency with black, so Apple's margin would only shrink the art there. The header and footer
mark sits beside the wordmark, where the full crop reads best at 36–40 px.

The DMG background design is in `assets/dmg/dmg-design.md`.
